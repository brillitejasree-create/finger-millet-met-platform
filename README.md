# finger-millet-met-platform


This platform is dedicated to aggregating, processing, and analyzing meta-data regarding finger millet (Eleusine coracana) performance, yields, and environmental traits.

## Project Structure
- `data/`: Raw and processed multi-environment trial (MET) datasets.
- `r_scripts/` & `python/`: Data cleaning, statistical modeling, and visualization scripts.
- `sql/`: Database queries for data extraction.
- `plots/` & `results/`: Generated figures, summary tables, and model outputs.
- `powerbi/`: Dashboards for interactive data exploration.
- `manuscript/`: Drafts and documentation for publication.
